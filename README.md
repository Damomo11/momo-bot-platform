# Bot 自托管平台

独立的 Microsoft OAuth2 Minecraft Bot 托管平台，面向 `mc.zenoxs.cn`。

平台只提供两种固定模式：

- 智能 Bot：持续在线，按小时计费，包含 Zenox 消息解析、SQLite 权限名单、锁定状态和游戏内命令。
- 签到 Bot：按计划上线，执行代码中固定的签到流程，成功后按次收费并自动下线。

两种模式都由平台统一处理 Microsoft OAuth、账号运行锁、资源包、固定协议版本、持续自动重连、运行状态和进程隔离。连接 `mc.zenoxs.cn` 时固定使用 Minecraft `1.21.11`；连接或登录超时后会继续使用同一版本重连，不再因为尝试完协议版本而自动停止。

## 启动

```bash
npm install
copy config.example.json config.json
npm start
```

默认地址为 `http://127.0.0.1:8788`。

用户可从云仓库导航栏直接进入平台。云仓库会签发 60 秒有效的本地 HMAC 登录凭证，平台使用玩家 ID 作为用户名，不要求再次注册或输入密码。`Damomo1` 会成为平台管理员，其他云仓库玩家为普通用户。本地注册默认关闭，管理员可以在“Bot 代码 -> 平台设置”中重新开启。

两个项目各自保存一份相同的 SSO 密钥：

- 云仓库：`data/bot-platform-sso.key`
- Bot 自托管平台：`data/cloud-store-sso.key`

密钥文件不会提交到 Git。两个服务没有启动依赖；云仓库只在用户点击入口时检查平台是否在线，平台验证凭证时不会反向访问云仓库。

管理员可以在网页中调整两种模式的价格和新用户初始金。新用户初始金默认是 `10 momoc`，仅在本地账号注册或云仓库玩家首次进入平台时发放，不追溯已有用户。管理员还可以编辑：

- `smart-runtime`：智能 Bot 固定代码。
- `signin-runtime`：签到 Bot 固定代码。

## 智能 Bot 权限与命令

用户可以在创建智能 Bot 时设置任意长度的命令前缀，也可以在“命令前缀”导航页或权限面板中修改，修改会立即热更新到对应 Bot。自定义前缀按 Bot 保存并在整个平台内唯一，不同用户也不能重复使用。无论是否设置自定义前缀，Bot 当前游戏名始终可以作为前缀，例如 `NanKinz2查白 Steve` 或 `NanKinz2解锁`。白名单、黑名单和超管按平台用户隔离，并由同一用户的全部智能 Bot 共享；普通锁和超级锁按单个 Bot 保存。前缀、名单、临时到期时间和锁定状态都存入 SQLite，平台重启后不会丢失。

- 公开查询：`查白`、`查黑`、`查超管`、`开盒`、`near`、`near 玩家名`。
- 白名单操作：`上车`、`下车`、`开宝库`、`清空`、`拿出 物品中文名或id`、`副手`、`丢弃 物品中文名或id`、`切换 1-9`、`攻击`、`定时灾厄之瓶 开|关`。

`拿出` 和 `丢弃` 都支持官方中文物品名、完整 ID 或省略命名空间的 ID，例如 `拿出 石头`、`拿出 minecraft:stone`、`丢弃 stone`。`拿出` 会把指定物品装备到主手，`副手` 会把当前主手物品放入副手，`丢弃` 会丢出背包和快捷栏中的全部指定物品。

`攻击` 会对机器人准星 3.5 格内命中的实体发送一次原版攻击；没有命中实体时仍会挥动主手。剑的横扫伤害由服务器按原版规则判断，通常要求攻击冷却充分、机器人在地面、未冲刺且移动速度足够低。

`定时灾厄之瓶` 从关闭切换为开启时会立即饮用一瓶；饮用成功后开始下一个 31 分钟周期。饮用失败不会推进周期，而是在 1 分钟后重试。
- 白名单命令：`指令`、`锁定`、`解锁`、`状态`、`版本`。
- 超管命令：`重启`、`加白`、`去白`、`加黑`、`去黑`、`加超管`、`去超管`、`临时加白`、`临时加黑`、`超级锁定`、`超级解锁`。检测到新版本时的主动升级提醒只会私聊超管。

自定义任务可以声明最多 10 个参数，并在任意步骤参数中用 `{参数名}` 引用。例如任务“自动放置”声明 `x y z` 后，可在放置步骤填写 `{x} {y} {z}`，并在指令步骤填写 `say 当前放置点在({x},{y},{z})`；玩家使用 `自动放置 100 64 200` 即可执行。只有一个参数时，该参数会接收任务名后的整段文本，适合“自动喊话 内容”一类任务。带参数任务也可用 `定时任务 任务名 间隔 参数...` 开启定时执行。

所有自定义消息文本都支持 `{sender}` 通用变量，运行时会替换为本次命令的发起玩家。例如将某条回复设置为 `/msg {sender} 操作完成`，即可把该回复改为私信发送。

`near` 不带参数时查询距离发送者最近的三名玩家，带玩家名时改为查询距离该玩家最近的三名玩家。地图接口仅提供 X/Z 坐标，因此距离按同一维度内的平面距离计算并四舍五入为格数；主世界、地狱和末地玩家不会相互混入结果。黑名单玩家会被静默忽略。超级锁定期间只有超管可以继续操作；`超级解锁` 会一次性清除超级锁和普通锁。普通锁定会拦截 `/tpa`、`/spawn`、`/back` 和 `/tpaccept` 等移动指令。非超管使用`指令`时还会拒绝 `/gmp`、`/pay`、`/msg` 和 `home` 族命令；换行和嵌套命令前缀对所有人禁用。

当服务器系统消息匹配“`✨ 玩家名 想要和你贴贴，输入 /peek accept 接受，或 /peek deny 拒绝`”时，智能 Bot 会查询发起玩家的权限；玩家在白名单且不在黑名单时，自动发送 `/peek accept`，其他情况不响应。

数据库、OAuth 缓存、运行目录、日志和 `config.json` 均由 `.gitignore` 排除。
